# Свидетельства

Каталог для проверяемых результатов, на которые ссылается `project.md`.

Правило курса: здесь хранятся **только те** результаты, на которые есть ссылка из `project.md`.
Полный служебный вывод инструментов сюда не складывается — только существенная часть,
достаточная для проверки вывода.

На момент сдачи паспорта (раздел 1) каталог пуст: апробация начинается на семинарах 07–09.

Планируемое наполнение по мере прохождения курса:

| Файл | Появится после | Что подтверждает |
|---|---|---|
| `baseline-tests.txt` | семинар 04 | прогон 17 существующих pytest-тестов на `v0.1.0-baseline` |
| `env-freeze.txt` | семинар 04 | фактические версии Python-зависимостей, на которых снят baseline |
| `sast-*.json` / `sca-*.json` | семинар 08 | результаты выбранных статических проверок |
| `sbom-v0.2.0.json` | семинар 08 | состав выпуска |
| `secret-scan.txt` | семинар 08 | проверка истории и рабочего дерева на секреты |
| `security-tests.txt` | семинар 09 | регрессионные тесты выбранного улучшения |
| `recheck-*.txt` | семинар 09 | повторная проверка «до и после» |

Что сюда **не** кладётся ни при каких условиях: содержимое локального `.env`, боевые ключи
API, корпоративный сертификат `backend/certs/yandex-ca.pem`, дампы реальных данных.
